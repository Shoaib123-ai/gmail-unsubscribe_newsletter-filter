# gmail-unsubscribe_newsletter-filter
An automated Gmail filtering workflow created with Zapier to identify and trash emails matching predefined keywords such as "unsubscribe" and "newsletter."

This project demonstrates a Zapier automation that filters incoming Gmail messages based on predefined keywords such as "unsubscribe" and "newsletter." Promotional emails and newsletters can quickly clutter an inbox after subscribing to various services. This workflow automatically detects such emails and moves them to the Trash before they appear in the inbox, reducing manual email management and improving productivity.
